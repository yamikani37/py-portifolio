# Yamikani Phiri - Developer Portfolio

A modern, responsive portfolio website built with Next.js, Tailwind CSS, and Shadcn/UI components.

## Features

- 🚀 **Modern Stack**: Next.js 15 (App Router), TypeScript, Tailwind CSS v4
- 🎨 **Beautiful Design**: Clean, minimal design with smooth animations
- 📱 **Fully Responsive**: Optimized for mobile, tablet, and desktop
- 🔧 **Shadcn/UI Components**: Reusable, accessible UI components
- 🔒 **Future-Ready**: Prepared for Supabase integration and admin dashboard
- ⚡ **Performance Optimized**: Fast loading with excellent Core Web Vitals
- 🎭 **Smooth Animations**: Framer Motion for delightful interactions

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **UI Components**: Shadcn/UI
- **Animations**: Framer Motion
- **Database**: Supabase (ready for integration)
- **Deployment**: Vercel

## Getting Started

1. **Install dependencies**
    ```bash
    npm install
    ```

2. **Set up environment variables**
    ```bash
    cp .env.example .env.local
    ```

3. **Run the development server**
    ```bash
    npm run dev
    ```

4. **Open [http://localhost:3000](http://localhost:3000)**

## Customization

1. Update personal information in `src/lib/constants.ts`
2. Add your projects to the `PROJECTS` array
3. Customize colors in `tailwind.config.js`
4. Modify sections in `src/components/sections/`

## Deployment

Deploy to Vercel by connecting your GitHub repository.
